# Financial Analysis Dashboard

A financial analysis project using Microsoft Excel and SQL to evaluate
revenue, expenses, profitability, departmental performance, and
cost-saving opportunities.

## Project Overview

The project provides an interactive financial overview to analyze
spending patterns, monitor profitability, compare departmental
performance, and support data-driven business decisions.

## Tools & Technologies

- Microsoft Excel
- SQL
- Pivot Tables
- VLOOKUP / XLOOKUP
- SUMIFS / COUNTIFS
- Excel Charts
- Data Cleaning
- Financial KPI Analysis

## Key KPIs

- Total Revenue
- Total Expenses
- Net Profit
- Profit Margin
- Cost-Saving Opportunities

## Dashboard Features

- Revenue vs. Expenses analysis
- Monthly profit trend
- Department-wise financial performance
- Expense category analysis
- Budget vs. Actual comparison
- Cost-saving opportunity analysis
- Interactive Excel filters
- Pivot-table based reporting

## SQL Analysis

SQL was used to extract and aggregate financial data, calculate
revenue and expenses, compare departmental performance, identify
high-cost categories, and analyze potential cost-saving opportunities.
